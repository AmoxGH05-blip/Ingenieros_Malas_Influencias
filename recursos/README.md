# Recursos

Carpeta de recursos compartidos del proyecto DYGSIS para el equipo (diseño, branding, etc.).

## branding/

Logo oficial de DYGSIS (Ingenieros Malas Influencias).

| Archivo | Descripción |
|---|---|
| `dygsis-logo-blanco.png` | Logo completo (insignia + texto), variante blanca. Usar sobre fondos oscuros. |
| `dygsis-logo-negro.png` | Logo completo (insignia + texto), variante negra. Usar sobre fondos claros. |
| `dygsis-icono-blanco.png` | Solo el ícono/emblema (sin texto), variante blanca. Para espacios reducidos (sidebar, favicon, avatares). |
| `dygsis-icono-negro.png` | Solo el ícono/emblema (sin texto), variante negra. |

Estos mismos archivos están copiados en `frontend/src/assets/branding/` para uso directo en los componentes de React. Si el logo cambia, actualiza ambas carpetas.
